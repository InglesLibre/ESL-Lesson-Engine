# ESL Lesson Engine

A JavaScript-based lesson delivery system for ESL/EFL classrooms, designed for international exam preparation and skills practice.

## Features

- **Automatic slide generation** from JSON
- **Multiple activity types**: Gap-fill, dropdown, multiple choice, matching, drag & drop, speaking
- **Theme support**: Baltic Blue and School Bus Yellow
- **Image support** via URLs
- **Teacher notes** generated from lesson metadata
- **Local storage** for student progress tracking
- **GitHub Pages** compatible
- **Keyboard navigation** and mobile support
- **Progressive Web App** ready
- **No external libraries** required
